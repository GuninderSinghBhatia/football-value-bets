# BetMind

Estimates La Liga match probabilities, compares them with bookmaker odds to find value bets, and learns from its results. **Paper trading only.**

## Structure

- `web/`: Next.js frontend (currently on mock data in `web/src/lib/mock-data.ts`)
- Backend (FastAPI), data pipeline and models: coming next

## Run the web app

```bash
cd web
npm install
npm run dev
```

Then open http://localhost:3000.
